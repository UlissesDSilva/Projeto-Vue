Projeto tem como intuito forma uma báse de conhecimento sobre backend, usando node como tecnologia por trás 

### Knex
-- Biblioteca usada para acessos de bancos relacionais - Query builder
Migration - comandos
  - knex init
  - knex migrate:make name_migrate
  - knex migrate:latest
  - Knex migrate:rollback

### Consign
-- Ajuda definir as dependencias dentro a aplicação


### Comandos
Postgres:  
  - psql -U postgres
  - \q
  - \l
  - \c nome_banco
  - \dt: Lista tabelas do banco atual
  - \d: Exibe detalhes de uma tabela


### Passport
Usado para o controle de autenticação

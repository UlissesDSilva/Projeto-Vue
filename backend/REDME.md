Projeto tem como intuito forma uma báse de conhecimento sobre backend, usando node como tecnologia por trás 

### Knex
-- Biblioteca usada para acessos de bancos relacionais - Query builder
Migration - comandos
  - knex init
  - knex migrate:make name_migrate
  - knex migrate:latest
  - Knex migrate:rollback

### Consign
